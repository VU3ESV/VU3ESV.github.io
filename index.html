01 About

LB9KJ is the Norwegian callsign of an amateur radio operator originally licensed in India as VU3ESV. The station operates from Haugesund on the south-west coast of Norway, with a second active station in Bangalore. Operating interests are HF DX on CW, SSB and the digital modes (FT8 / FT4 / Q65), with a strong technical bent toward radio automation, SDR tooling and Kenwood / FlexRadio integration — most of which is open-sourced on GitHub.

QSLs are confirmed exclusively via Logbook of The World. No bureau, no paper.

04 Projects

Open-source ham-radio tooling published on GitHub:

  • TCILibrary C# implementation of the Expert Electronics TCI protocol — talks to FlexRadio / SunSDR. C# · TCI · SDR
  • KenwoodTCPServer TCP server that fronts the Kenwood TS-990 / TS-890 serial interface, so any networked client can drive the radio. .NET · CAT · Kenwood
  • ESP32 Band Decoder ESP32 firmware that reads the live band from a Kenwood radio (via the Node-RED TCP server) and switches LPF relays accordingly. ESP32 · C++ · Hardware
  • Kenwood TCP Server (Node-RED) Node-RED flow that exposes the Kenwood CAT stream over TCP for downstream automation. Node-RED · MQTT
  • ESP32 Wi-Fi MAC Finder Small C++ utility for ESP32 device provisioning. ESP32 · C++
  • pihpsdr (fork) Personal fork of John Melton's pihpsdr — Raspberry Pi front-end for HPSDR / Hermes Lite radios. C · Linux · SDR

05 VU3ESV — sister station

When not in Norway, the same operator is QRV from Bangalore, India as VU3ESV. The Bangalore shack is built around a Kenwood TS-990SP with the home-grown Node-RED / ESP32 automation stack listed above. QSL policy is identical: LOTW only.
