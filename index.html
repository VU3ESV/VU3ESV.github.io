01 · About

The Station

LB9KJ is the Norwegian callsign of an amateur radio operator originally licensed in India as VU3ESV. The station operates from Haugesund on the south-west coast of Norway, with a second active station in Bangalore.

Operating interests are HF DX on CW, SSB and the digital modes (FT8 / FT4 / Q65), with a strong technical bent toward radio automation, SDR tooling and Kenwood / FlexRadio integration — most of which is open-sourced on GitHub.

QSLs are confirmed exclusively via Logbook of The World. No bureau, no paper.

04 · Projects

Open-Source Ham Tooling

Open-source ham-radio tooling published on GitHub. Most of these target the Kenwood TS-990 / FlexRadio integration that drives both shacks.

TCILibrary
C# implementation of the Expert Electronics TCI protocol — talks to FlexRadio / SunSDR. Provides the building blocks for any .NET client that needs RX/TX control over TCI.
C#TCISDRFlexRadio
View repo on GitHub
Active
KenwoodTCPServer
TCP server that fronts the Kenwood TS-990 / TS-890 serial interface, so any networked client can drive the radio. Decouples the CAT line from a single PC and lets the rest of the shack talk to the radio over LAN.
.NETCATKenwoodTCP
View repo on GitHub
Active
ESP32 Band Decoder
ESP32 firmware that reads the live band from a Kenwood radio (via the Node-RED TCP server) and switches LPF relays accordingly. Drives the low-pass filter bank without any host PC in the loop.
ESP32C++HardwareLPF
View repo on GitHub
Active
Kenwood TCP Server (Node-RED)
Node-RED flow that exposes the Kenwood CAT stream over TCP for downstream automation. Pairs with the ESP32 band decoder and the rest of the shack control stack.
Node-REDMQTTCAT
View repo on GitHub
Active
ESP32 Wi-Fi MAC Finder
Small C++ utility for ESP32 device provisioning. Surfaces the device's Wi-Fi MAC so it can be registered with the access point before the rest of the firmware comes up.
ESP32C++Wi-Fi
View repo on GitHub
Active
pihpsdr (fork)
Personal fork of John Melton's pihpsdr — Raspberry Pi front-end for HPSDR / Hermes Lite radios. Tracks upstream while carrying local tweaks.
CLinuxSDRHPSDR
View repo on GitHub

05 · Sister Station

VU3ESV — Bangalore

When not in Norway, the same operator is QRV from Bangalore, India as VU3ESV.

The Bangalore shack is built around a Kenwood TS-990SP with the home-grown Node-RED / ESP32 automation stack listed in the Projects section above.

QSL policy is identical: LOTW only. Both callsigns log into the same upload pipeline, so confirmation appears in your LOTW account within a day or two of the QSO.
